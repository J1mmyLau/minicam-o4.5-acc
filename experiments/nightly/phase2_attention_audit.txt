=== Path C: Non-fused CANN/NPU (decomposed) ===
Not explicitly implemented as a single function, but building blocks exist:
- ggml_cann_mul_mat (QK^T and output projection)
- ggml_cann_softmax (with scale + ALiBi)
- ggml_cann_diag_mask (causal masking)
- ggml_cann_rope (position encoding)
- ggml_cann_scale, ggml_cann_add

A custom ggml_cann_flash_attn_ext decomposition could use:
  QK^T = MUL_MAT(Q, K^T) → SOFT_MAX(scale + mask) → MUL_MAT(attn, V)
But: this would require implementing a replacement for ggml_cann_flash_attn_ext
that uses the CANN primitives instead of aclnnFusedInferAttentionScoreV2.

Performance cost: likely significant (3 separate kernel calls + intermediate tensors)
vs 1 fused kernel call.

=== PRODUCTION CANDIDATES ===

Candidate A: Safe-shape dispatch (shape-aware CPU fallback)
  Implementation: add shape check in supports_op for GGML_OP_FLASH_ATTN_EXT
  Pros: minimal change, guaranteed correct, no cache contamination
  Cons: CPU attention cost for large prefill rounds
  Risk: low

Candidate B: Q-chunking (n_ubatch reduction)
  Implementation: split large prefill into smaller micro-batches
  Pros: stays on CANN fused, no CPU fallback

  Risk: medium (need to prove semantic equivalence)

  Pros: stays on NPU, no fused kernel
  Cons: higher perf cost, needs new code, no existing implementation
