# Demo 演示视频脚本

> 录制一份展示 MiniCPM-o 4.5 全模态能力的视频（10–15 分钟，或分段合集）。
> 画面建议同时展示：浏览器 Demo + Server 日志 + `npu-smi` + 时间戳 + 候选 commit。

---

## 视频硬性要素（评审必看）

- 画面一角固定显示：候选 commit `bdd4550`、server SHA `db258375…`、libommi `c4b16937…`
- `npu-smi` 窗口常驻（展示 910C 状态、HBM、利用率）
- 录制工具显示时间戳
- Server 日志可见（可切换窗口）

## 分镜脚本

| 段 | 时长 | 内容 | 验证点 |
|---|---|---|---|
| 0. 环境 | 30s | npu-smi + env_check.sh 输出 + 版本 manifest | 环境合规 |
| 1. 启动 | 1min | start_server.sh → health OK；模型加载日志 | 服务可启动 |
| 2. 纯文本 | 1min | 文本问题 → 完整回答 | D3 |
| 3. 单图 | 1min | 上传图片 + 问题 → 图文理解 | D4 |
| 4. 单音频 | 1min | 上传音频 → 理解作答 | D5 |
| 5. 视频/视听 | 2min | 视频+音频 → 视音频理解 | D6 |
| 6. 语音对话 | 2min | 语音输入 → 文本/流式语音输出 | D7 |
| 7. 连续多轮 | 2min | 同一会话 3-4 轮，上下文保持 | D8 |
| 8. 连续语音 | 2min | 长句 TTS，逐 chunk 连续无断裂 | 音频连续性 |
| 9. 长稳 | 3min | 连续交互（或 10min 长稳剪辑） | D10 |
| 10. 断连恢复 | 1min | 中断连接 → 服务存活 → 新会话成功 | D11 |
| 11. 错误恢复 | 1min | 空输入/损坏媒体 → 明确错误、不崩溃、后续正常 | D12 |
| 12. 收尾 | 30s | 日志无 error（cpu_fallback=0 / cann_error=0）→ commit/SHA 复显 | 稳定性 |

## 每段录制检查（录制中实时对照）

```text
□ 该段输入/输出是否按预期
□ 音频 chunk 是否连续（无长停顿/截断/爆音）
□ 无 HTTP 500 / 无崩溃 / 无异常退出
□ npu-smi 显示正常负载
□ 时间戳连续（无跳变）
```
